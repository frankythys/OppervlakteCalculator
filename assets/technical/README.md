# Technical calculator assets

Technical illustrations used by calculator screens live here.

- `pipes/` — round pipe, insulated pipe and cladding
- `bends/` — elbows and bends
- `plates/` — flat sheet and plate layouts
- `flanges/` — flange illustrations
- `valves/` — valve illustrations
- `cones/` — cone/reducer illustrations

Keep all runtime calculator images in these folders and reference them through `src/components/technical/technicalImages.ts`.
